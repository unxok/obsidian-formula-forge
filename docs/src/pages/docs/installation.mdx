Installation is easy-peasy!

## In app

Get the latest official release that is automatically reviewed and approved on the [Obsidian Community site](https://community.obsidian.md/plugins/formula-forge)

1. Click [this](obsidian://show-plugin?id=formula-forge) or search `formula-forge` in the Community Plugins store within the Obsidian app
2. Click `install` then `enable`

## Using BRAT

Get any release, official or not, with the [BRAT plugin](https://community.obsidian.md/plugins/obsidian42-brat)

1. Install and enable the BRAT plugin
2. Go to the BRAT plugin settings and click `Add beta plugin`
3. Enter the Formula Forge repository url: `https://github.com/unxok/obsidian-formula-forge`
4. Select a version with the dropdown and click `Add plugin`
