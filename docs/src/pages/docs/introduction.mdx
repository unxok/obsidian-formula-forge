Formula Forge is a plugin for [Obsidian](https://obsidian.md) which aims to extend the functionality of formulas to allow things such as live preview formulas, global formula properties, and custom functions, as well as additional global functions.

## What is a formula?

From the [official Obsidian Bases documentation](https://obsidian.md/help/bases/syntax#Formulas):

> Formula properties support basic arithmetic operators and a variety of built-in Functions.

There are plenty of examples and additional information on how to write formulas in the official Obsidian documentation, so read up on that first before you use this plugin.

## So what else do I need to learn?

Nothing!

Formula Forge builds **on top of** Obsidian's built-in formulas, so there's **no new syntax learn** to use this plugin.
